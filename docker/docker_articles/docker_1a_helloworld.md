## Docker Hello World (Hola Mundo de Docker)

Docker Hello World es una imagen simple de Docker que sirve como prueba para verificar que Docker está instalado y funcionando correctamente en tu sistema. A menudo se utiliza como el primer paso para aprender Docker, ya que proporciona una manera sencilla de confirmar que el motor de Docker puede descargar imágenes desde Docker Hub y ejecutar contenedores.

Para ejecutar la imagen Docker Hello World, puedes usar el siguiente comando en tu terminal:

```bash
docker run hello-world
```
Este comando descargará la imagen Hello World desde Docker Hub (si no está presente en tu sistema) y la ejecutará en un nuevo contenedor. Al ejecutarlo, deberías ver un mensaje indicando que Docker está funcionando correctamente, junto con información sobre la imagen y el contenedor.

Si ves el mensaje "Hello from Docker!" seguido de información adicional, significa que Docker está funcionando correctamente en tu sistema. Si encuentras algún error, puede indicar un problema con la instalación o configuración de Docker.
